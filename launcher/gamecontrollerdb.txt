# ONS Launcher 手柄映射（SDL GameController 标准格式，与 SDL_GameControllerDB / PortMaster 通用）
# 部署到 ons_launcher 同目录；启动时加载，新增品牌只需追加一行。
# launcher 以 guide 作为菜单键；未映射 guide 的设备退回原始按键 10。
# a/b/x/y 是 SDL 的位置语义（a=下 b=右 x=左 y=上），不是按键上印的字母；
# launcher 以 b（右键）为确认、a（下键）为返回。
# GUID 以 ons_launcher 日志 "[Launcher] Controller: ... guid xxx" 打印的为准：
# 掌机系统 SDL 生成的 GUID 不含设备名 CRC（第 3~4 字节为 0000），与 SDL 官方新版格式不同。
